# Student Helper

Лендинг Student Helper: закреплённая шапка, главный экран, форма оценки, услуги с ценами, реальные примеры работ, порядок заказа, отзывы, FAQ и контакты. React + Vite, без UI-фреймворка.

## Запуск
Node.js 22.12+ или актуальная LTS-версия.

```sh
npm ci
npm run dev
```

Локальный адрес выводит Vite (по умолчанию http://127.0.0.1:5173).

```sh
npm run lint
npm run build
npm run preview
```

Структура и правила: [AGENTS.md](AGENTS.md). Источники перенесённого содержания и оставшиеся интеграции: [docs/CONTENT_SOURCES.md](docs/CONTENT_SOURCES.md).

Форма проверяет описание и согласие, позволяет выбрать и удалить файл до 20 МБ. Карточка услуги заполняет описание, только если оно пустое. Серверная отправка ещё не подключена; интерфейс сообщает об этом после проверки задания. Содержание, цены, отзывы и статистика перенесены со studenthelper.ru. Просмотр PDF и связь с менеджером доступны по реальным ссылкам исходного сайта.

Вспомогательные материалы находятся в `operation/` и не попадают в Git.
