# Student Helper

Сайт Student Helper: главная и все 24 внутренние страницы прежнего сайта в новом дизайне. Каталог из восьми услуг, цены, гарантии, библиотека 11 работ, пять памяток, FAQ, документы и оплата СБП. React + Vite, без UI-фреймворка.

## Запуск
Node.js 22.12+ или актуальная LTS-версия.

```sh
npm ci
npm run dev
```

Локальный адрес выводит Vite (по умолчанию http://127.0.0.1:5173).

```sh
npm run lint
npm run build
npm run preview
```

Структура и правила: [AGENTS.md](AGENTS.md). Источники: [docs/CONTENT_SOURCES.md](docs/CONTENT_SOURCES.md). Адреса, сборка и оставшиеся интеграции: [docs/SITE_MIGRATION.md](docs/SITE_MIGRATION.md).

Сборка создаёт в `dist/` отдельный HTML с полным содержимым для каждого адреса, `404.html`, `sitemap.xml` и `robots.txt`. Хостинг должен обслуживать вложенные `index.html` и возвращать `404.html` со статусом 404 для неизвестных адресов. Публикация на боевой сервер выполняется отдельно.

Форма открывается по кнопке заказа, проверяет описание и обязательное согласие, позволяет выбрать и удалить файл до 20 МБ. Карточка услуги заполняет только пустое описание. Серверная отправка ещё не подключена; форма честно сообщает об этом. PDF хранятся в этом репозитории, связь с менеджером ведёт в действующий Telegram. СБП использует существующий API и банковский виджет; для проверки реального платежа нужна выданная менеджером ссылка.

Вспомогательные материалы находятся в `operation/` и не попадают в Git.
