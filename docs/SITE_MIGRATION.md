## Подача и взаимодействия

Услуги оформлены строками каталога и отдельными страницами с примером, результатом, материалами для менеджера и FAQ. Цены и подписка перенесены из источника. Итоговые условия согласуются индивидуально.

В библиотеке 11 настоящих работ: поиск, фильтры, нативный диалог и полные PDF. PDF и превью хранятся локально, без зависимости от старого сайта. Статьи и юридические документы получили удобную ширину текста и оглавление; исходный текст сохранён. Общая шапка, подвал и диалог заявки доступны на внутренних страницах.

## Сборка

Обычные ссылки ведут между страницами. `npm run build` сначала собирает клиент, затем рендерит React в отдельные HTML через серверную точку входа. Содержимое, заголовки и метаданные доступны до выполнения JavaScript. Клиент гидратирует готовую разметку. Никакой постоянно работающий Node-сервер для публикации не требуется.

`dist/` — готовый сайт; `operation/ssr/` — промежуточный результат. Сборка добавляет canonical и Open Graph, карту сайта и правила для поисковых роботов. Страницы СБП и 404 помечены `noindex`; платёжная страница также использует `no-referrer`.

## Интеграции

- Отправка заявки и файлов ещё не подключена. Текущий диалог сохраняет черновик при закрытии и показывает сообщение о неподключённой отправке. Галочка согласия обязательная, без предварительного выбора, со ссылками на перенесённые документы.
- Страница СБП сохраняет контракт прежнего сайта: UUID из `?payment=`, конфигурация из `app.studenthelper.ru/api/v1/finance/tbank/sbp/<id>/config/`, официальный SDK `integrationjs.t-static.ru`. Некорректная ссылка не вызывает API и предлагает связаться с менеджером. Реальный платёж не проводился; доступность API/CORS и банковский сценарий требуют отдельной проверки с выданной ссылкой.
- Боевой сайт и конфигурация сервера при переносе не изменялись.
