# Первый экран

## Визуальная система
Белый фон с лёгким мятным свечением, зелёный акцент, Manrope, тёмные CTA, мягкая геометрия. На широком экране слева текст, справа крупная композиция из иконок владельца. Форма скрыта в модальном окне. Первый экран вместе с шапкой занимает высоту окна, статистика начинается ниже него. На телефоне иллюстрация располагается под текстом и кнопками.

## Поведение
- Все кнопки заявки открывают одну форму в нативном dialog. Выбор услуги подставляет её в пустое описание, не затирая черновик.
- Окно закрывается по крестику, Escape или клику по подложке. Фокус возвращается к кнопке, прокрутка страницы сохраняется. Описание, файл и согласие остаются при повторном открытии в рамках текущей страницы.
- Начальный фокус — на заголовке формы: мобильная клавиатура открывается только после выбора поля. Согласие на обработку данных обязательно и изначально не отмечено.
- Центральный элемент мягко покачивается, четыре иконки парят с разным ритмом, точка на орбите медленно движется. На компьютере вся сцена слегка следует за курсором. CSS-трансформации не меняют размеры разметки.
- Движение останавливается вне экрана, в скрытой вкладке и при открытом диалоге. При системной настройке уменьшения движения анимации и реакция на курсор отключены.
- «Узнать больше» ведёт к показателям сервиса.
- Шапка закреплена при прокрутке. Меню ведёт к услугам, примерам, процессу, отзывам, FAQ и контактам; мобильное меню закрывается после перехода.
- Описание задания обязательно. Файл необязателен, ограничен 20 МБ, доступно удаление выбранного файла.
- После проверки полей показывается честное сообщение о неподключённой отправке. Данные не сохраняются и не отправляются.

## Следующий этап
Согласовать адрес API или интеграцию с ботом, способ связи с заявителем и правила работы с файлами. Только после этого включать отправку. Нижние разделы добавлены по запросу владельца; источники содержания и состояние интеграций — в CONTENT_SOURCES.md.

## Исходники
Из предоставленного ZIP использованы coursework, analytics, flask, diploma и presentation. Логотип предоставлен отдельным SVG. Шрифт Manrope используется локально с OFL-лицензией.
